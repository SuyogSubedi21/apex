# Apex Construction

Premium static construction company website built with React, Vite, Tailwind CSS, and Framer Motion.

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- Fully static frontend-only deployment

## Local Development

```bash
npm install
npm run dev
npm run build
```

## Vercel Deployment Settings

- Framework: `Vite`
- Build command: `npm run build`
- Output directory: `dist`

No backend, database, or environment variables are required.

## GitHub Push Commands

```bash
git init
git add .
git commit -m "Add Apex Construction website"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/apex-construction.git
git push -u origin main
```

After pushing, import the GitHub repository into Vercel and deploy with the settings above.
